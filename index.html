パッシェンの法則とは

TOPへもどる

  • 対向する電極間に高電圧を印加していくと、ある限界値を超えた時に光や音を伴いながら放電が始まる。これを火花放電という。
  • 気体中で放電が始まる電圧(火花電圧、絶縁破壊電圧)Vsは、その時の圧力pと電極間距離dの積に依存することが知られており、それを「パッシェンの法則」という。ある特定のpd値で最も放電しやすくなる(Vsが低くなる)ことが知られている。
  • タウンゼントの放電理論では、火花電圧Vsは次式で与えられる。
    • Vs = B⁢pd ln ( A⁢pd ln ( 1+1/γ ) )
  • ここで、Vs: 火花電圧、A、B: 気体の種類で決まる定数(A=1/λ1、B = φi/λ1)、φi：電離エネルギー、γ：イオンによる二次電子放出率(電極表面状態や材質等に依存)である。λ1はp = 1 Torrでの平均自由行程である。(高村秀一、プラズマ理工学入門より)
  • この式において、下記のようにVsとpdをyとxで規格化する。
    • y = A⁢Vs B⁢ ln ( 1+1/γ ) , x = A⁢pd ln ( 1+1/γ )
  • すると、単純な次式を得る。
    • y = x lnx
  • つまり、規格化されたVs(y)を規格化されたpd(x)に対して1本の曲線で表すことができる。その図を右に示す。これがパッシェン曲線である。この曲線は気体や電極の種類に依らない。(一般には、上のVsの式をパッシェン曲線と呼ぶことが多い)
  • この曲線の最も重要な点は、あるpdでVsが極小値をとるということである。
  • pdが極端に小さいと、電離が十分進まないのでVsは高くなる。一方、pdが大き過ぎると、衝突が多すぎて電子が十分なエネルギーまで加速されないため再び電離が不十分となり、Vsは高くなる。両者の中間のpdにてVsは極小値をとる。
  • 参考：プラズマの基礎実験

実験装置の基本構成

TOPへもどる

  • 装置の基本構成を右図に示す。
  • 真空容器内に対向する2つの平板電極を配置し、電極間距離(d)や圧力(p)を変えて、放電開始電圧(Vs)を測定する。
  • 横軸をpd、縦軸をVsとして測定結果をプロットして(いわゆるパッシェン曲線)、Vsのpやdへの依存性を調べ、理論曲線との比較を行う。
  • 気体として空気、窒素、水素、ヘリウムを用いる。
  • 余裕があれば、電極形状(板、針など)を変え、放電条件の変化を調べると面白い。

実験装置全体

真空容器内の対向電極

当初に取り付けた対向電極の状態。しかし、実験を始めてみると、圧力によっては対向した電極部以外で、つまり、電極の一部と真空容器(ステンレス)間で放電した。

そこで、放電が電極間以外で発生するのを防ぐために、電極全体をカプトンフィルム(厚み0.15 mm)でカバーした。

実験方法

TOPへもどる

手順

  1. ベローズの長さを変え、電極間隔dを設定する。
  2. 真空容器を排気し(~10-4 Pa)、その後所定の気体をゆっくり導入し、目的の圧力にする。
  3. 圧力pが一定になったら、印加電圧を徐々に上げていき、火花放電電圧Vsを記録する。
  4. 記録後、次の圧力に設定する。測定は、2kV以下の電圧で放電する圧力範囲で行う。
  5. 電極間距離d(右図)を5、10、15 mmと変え、同様の測定を行う。
  6. 気体の種類を変え、1～5を繰り返す。

電極間隔

測定回路図

  • 右回路図において、高電圧電源の電圧VHを徐々に上げながらVVとVIを記録していく。放電時には、R4に電流が流れるため、VIが急激に上昇する。同時にVVが少し下がる。下がる直前のVVの抵抗比倍(～1000倍)を放電電圧Vsとした。
  • 実験では、感電しないよう十分注意すること。導入端子には保護カバーを取り付ける。配線の接続部には絶縁テープを巻く。アースは必ずとること。

測定結果

TOPへもどる

  • 空気、窒素、水素、ヘリウムについて測定を行った。
  • 空気、窒素、水素については、pdに対してVsの極小値が観測され、パッシェン曲線をかなりうまく測定できた。
  • 特に極小値より大きいpdの範囲では、各dの測定値はよく一致した。
  • しかし、極小値より小さいpdの範囲ではVs測定値のバラツキが目立ち、小さいdで低いVs値となる傾向が見られた。
  • 原因としては、dが小さい場合、対向する電極間以外に、電極板を回り込むような(つまりdよりも大きい)パスで放電が始まるからと考えられるが、さらなる確認実験が必要である。
  • ヘリウムについては、各測定でバラつきが大きかった。ガス配管の接続が不十分だったのでガス導入系の問題ではないかと疑っているが、これも要確認である。
  • 空気と水素についての例を以下に示す。

空気

  • 上のd = 5 mm, 10 mm, 15 mmの結果を横軸をpdにしてまとめると右図のようになる。
  • 高い圧力側ではよく一致しているが、極小値より低い圧力の場合、dが小さい時にずれが大きい。
  • dが小さいとVsは小さい傾向がある。
  • Vsが極小となるpdは~700 Pa mmである。資料プラズマの基礎実験での値とほぼ一致している。
  • 窒素についてもほぼ同様の結果を得た。

水素

  • 上のd = 5 mm, 10 mm, 15 mmの結果を横軸をpdにしてまとめると右図のようになる。
  • 空気の場合と同様、高い圧力側ではよく一致しているが、極小値より低い圧力側でずれが大きい。dが小さいとVsは小さい傾向がある。
  • Vsが極小となるpdは~3000 Pa mmである。資料プラズマの基礎実験での値(約2000 Pamm)よりやや高いが、空気(窒素)より高い傾向は一致している。
